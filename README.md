# Intaglio: support and privacy

The support and privacy pages for Intaglio, an iPhone app for sharing your details at
conferences.

- Support: https://meyricke.github.io/intaglio/
- Privacy policy: https://meyricke.github.io/intaglio/privacy.html

The HTML here is generated from the app's sources and published by a script; changes made
directly in this repo are overwritten. The pages load nothing from anywhere else and run no
scripts.
